Label pendek berbentuk pil untuk jenjang, status, dan tenggat.

**Yang perlu disediakan konsumen:** teks satu sampai tiga kata. Kelas `rt-badge` ditambah varian `brand`, `sky`, `sun`, `ember`, `leaf`, atau tanpa varian untuk netral.

- Pasangkan varian dengan makna: `leaf` untuk hal baik atau tersedia, `ember` untuk tenggat atau intake, `sun` untuk kebaruan, `brand` dan `sky` untuk kategori.
- Teks memakai token `*-ink` di atas `*-soft`, sehingga lolos kontras 4.5:1 di kedua tema.
- Jangan menumpuk lebih dari tiga badge pada satu kartu.
