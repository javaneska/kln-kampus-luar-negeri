Isian satu baris dengan label di atas, teks bantuan di bawah, dan keadaan galat.

**Yang perlu disediakan konsumen:** `label` yang terhubung lewat `for` dan `id`, nilai awal atau `placeholder`, dan pesan galat bila ada. Tinggi minimum 44px.

- Label selalu tampil; `placeholder` hanya contoh format dan tidak menggantikan label.
- Tepi memakai `line-strong` (kontras 3:1). Fokus menambah cincin `focus` dan tepi `brand`.
- Galat memakai tepi `danger` 2px, ikon, dan kalimat yang menjelaskan cara memperbaiki. Warna saja tidak cukup.
- Teks bantuan memakai `ink-muted` dan menjelaskan mengapa data diminta, bukan mengulang label.
