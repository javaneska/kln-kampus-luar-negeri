Bagian pembuka halaman beranda: tagline resmi sebagai judul, satu kalimat penjelasan, dua tombol, dan ilustrasi busur horizon dari blok warna identitas.

**Yang perlu disediakan konsumen:** judul (tagline resmi), satu kalimat pengantar maksimal dua baris, tombol utama dan tombol pendamping.

- Judul `display-xl` berisi tagline persis: "Satu rencana, banyak kampus dunia." Hanya satu `h1` per halaman.
- Tombol utama memakai varian `accent` (kuning) sebagai satu-satunya sorotan di layar; tombol pendamping `secondary` membuka chat Aura.
- Ilustrasi dibangun dari lima blok (`brand`, `sun`, `sky`, `ember`, `brand-soft`) dan tiga busur `surface-100`. Jangan menambah foto di belakang teks.
- Pada lebar di bawah 720px susunan menjadi satu kolom dan ilustrasi mengecil.
- Kalimat pengantar tidak boleh memuat angka kampus atau biaya yang belum diverifikasi.
