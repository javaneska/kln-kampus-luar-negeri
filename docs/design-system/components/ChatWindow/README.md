Jendela chat Aura (Asisten Utama Rencana Edukasi) lengkap dengan kepala, isi percakapan, chip saran, indikator mengetik, kolom tulis, dan catatan batas jawaban.

**Yang perlu disediakan konsumen:** daftar pesan (gunakan `ChatBubble`), chip saran, penanganan kirim, dan tautan serah terima ke konselor (WhatsApp atau jadwal).

- Kepala memuat avatar kuning bertuliskan "A", nama "Aura", dan keterangan "Asisten AI dari KLN". Pengguna selalu tahu bahwa lawan bicaranya AI.
- Catatan di bawah kolom tulis wajib tampil: untuk biaya, syarat, dan tenggat, pengguna diarahkan ke konselor.
- Chip "Bicara dengan konselor" selalu tersedia setelah jawaban yang menyangkut biaya, syarat, atau tenggat.
- Indikator mengetik statis; bila ingin beranimasi, hormati `prefers-reduced-motion`.
- Lebar maksimum 400px, sudut `radius-xl`, bayangan `shadow-md`. Di layar kecil jendela memenuhi lebar layar dengan margin `space-4`.
