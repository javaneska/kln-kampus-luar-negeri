Penampil logo KLN pada latar terang dan gelap, beserta aturan pemakaian dasar.

**Yang perlu disediakan konsumen:** latar yang sesuai. Versi navy hanya di atas latar terang; versi putih hanya di atas latar gelap atau `brand`.

- Ambil file dari `assets/Logos/`; jangan menggambar ulang atau menyusun ulang huruf.
- Jangan mewarnai ulang atau memberi bayangan, gradien, atau kontur.
- Lebar minimum 120px. Di bawah itu tulisan "KAMPUS LUAR NEGERI" tidak terbaca.
- Ruang bebas minimal setengah tinggi huruf K di semua sisi (usulan).
- Pada header situs, tampilkan logo di sisi kiri dengan tinggi sekitar 40px dan tautkan ke beranda.
