Logo KLN (Kampus Luar Negeri) dalam dua versi warna tunggal. Format utama adalah SVG vektor (rasio 612 x 294,64); PNG transparan 2550 x 1228 tersedia sebagai cadangan. Pakai dengan `<img>` apa adanya.

- `kln-logo-navy.svg` dan `kln-logo-navy.png`: tinta navy `#0e223f`. Untuk latar terang (`surface-100`, `surface-raised`, `brand-soft`, putih).
- `kln-logo-white.svg` dan `kln-logo-white.png`: tinta putih `#ffffff`. Untuk latar `brand`, navy gelap, foto yang digelapkan, dan tema gelap.

Lebar minimum 120px. Jangan diubah warna, bentuk, atau urutan hurufnya.
